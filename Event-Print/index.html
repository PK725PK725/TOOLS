批次照片資料夾規範與上傳方式
  1. 照片格式限 JPG、JPEG、PNG 或 WebP；每位人員建議只準備一張照片。
  2. 照片檔名須與名單中的「姓名」完全相同，例如名單為「王小明」，照片請命名為「王小明.jpg」。
  3. 請按「選擇資料夾」選取整個資料夾，或直接將整個資料夾拖入上方區域；資料夾中的子資料夾也會一併讀取。
  4. 若名單有同名人員，請在 CSV 的「照片檔名」欄填入各自不同的完整檔名，再使用相同檔名準備照片。
  5. 批次處理前可選擇「取代既有照片」或「略過已有照片」；未配對及同名衝突會顯示在下方結果區。
