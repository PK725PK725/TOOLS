① 快速選取
① 快速選取｜新手操作
  1. 先加入圖片並點選要編輯的縮圖。
  2. 如標誌位於固定的右下角或左上角，可試用對應預設；其他位置請改用畫布上方的「框選」。
  3. 檢查畫面上的綠色遮罩是否只蓋到要去除的文字或標誌；利用「筆刷」補選，或用「擦遮罩」排除正常畫面。
  4. 文字較亮時，可先框選小範圍，再按「亮色精選」，由程式輔助找出亮色字樣。

注意：整合遮罩支援 KlingAI 與兩種 DreaminaAI 版型。請放大檢查右下角是否對齊，其他版型可用手動選區。

按此預覽遮罩。單張和批次修復都會逐張檢查右下角，即使已有手動選區也會清除辨識到的標誌。

依亮度與局部對比輔助選取。可調整門檻後重新精選，並檢查白衣或亮色背景是否誤選。

② 修復細節
② 修復細節｜參數怎麼調？
  1. 筆刷大小：控制塗抹選區寬度，細文字用小筆刷、大片標誌再加大；數值以原圖像素計。
  2. 邊緣羽化：讓修補區域邊緣更自然。建議先從 0～3 px 試起，過高可能讓字跡邊緣殘留或接縫變糊。
  3. 白色判斷亮度：只影響「亮色精選」。調低較容易選到亮色，也更可能誤選背景；調高選取較嚴格，可能漏掉暗淡的文字邊緣。
  4. 修補方式：先選「局部智慧修補（推薦）」，簡單背景可試平滑模式，複雜紋理可試細節模式。

精準字形修復：以字形遮罩定位白色及半透明筆畫，再沿周圍的底色與紋理修補。文字壓住人物邊界時，可放大檢查接縫。

注意：參數不能把原本被遮住的細節百分之百還原。若標誌蓋到人物輪廓、衣物邊線或複雜花紋，請縮小遮罩並搭配「仿製」工具做手動細修；修復前後應以 100% 縮放比較。

修補方式怎麼選？

局部智慧修補：以附近未遮住的像素推測補上內容，適合先試用。

平滑背景修補：較適合天空、牆面等變化少的背景，可能抹平細節。

細節紋理修補：較重視局部紋理，運算可能較慢，並不保證每張都比較自然。

注意：這些是本機影像演算法，不是能重建真實原始畫面的生成式 AI。先修復一張、檢查結果，再決定是否批次套用。

③ 批次處理
③ 批次處理｜一次修多張
  1. 在左側圖片清單勾選要處理的圖片，至少保留一張勾選。
  2. 先在目前圖片上完成框選或筆刷遮罩，建議點「修復目前圖片」確認效果。
  3. 勾選「將目前手動選區套用到尚未標記的勾選圖片」：程式依相對位置縮放選區，套用到尚未標記的勾選圖片；若取消勾選，會優先使用各張的標記，沒有標記時會右下角浮水印遮罩標誌。
  4. 按「批次修復勾選圖片」，觀察成功、失敗、略過與進度，再下載結果。

注意：不同長寬比、構圖或標誌位置，套用相同遮罩可能誤修人物或正常背景。請先測試 1～2 張；圖片多或尺寸大時分批處理。按取消後可能需完成目前的安全處理步驟才能停止。

每張圖都會自動檢查右下角。手動選區可補修其他位置，辨識到的標誌會一併修補。

⑤ 複檢方式
  • 局部並排：同時查看同一區域的原圖和修復圖，找殘字、斷線及不自然的色塊。
  • 瑕疵提示：用紅、藍、黃分別標出疑似色差接縫、紋理異常及殘字。人工選區請目視檢查殘字。
  • 滑桿與閃爍：比較修補前後的輪廓、陰影和紋理。
  • 差異熱區與實際改動：確認改動大小與範圍，包含批次套用及仿製圖章。
  • 修補區 100%+：以原圖像素比例定位並放大實際改動。

若清單標出「優先複檢」，請先開啟該張。建議同時查看局部並排和瑕疵提示。

④ 匯出設定
④ 匯出設定｜保留品質與下載
  1. 保持原本格式：適合不需轉檔的情況；程式會另存修復結果，不覆蓋來源檔。
  2. PNG：適合圖形、文字邊緣及透明背景；檔案可能較大。
  3. JPG：適合一般照片；不支援透明，重編碼可能略有畫質損失。
  4. WebP：通常可兼顧畫質與檔案大小，下載後請確認接收端支援。
  5. 檢查修復預覽後，可下載目前圖片；全部處理完成則按「下載全部成功圖片 ZIP」。

注意：JPG／WebP 品質百分比越高通常檔案越大，不等於修復越好。輸出維持原始寬高，但 EXIF 等中繼資料可能不完整保留。ZIP 只包含成功修復的檔案，下載後請開啟檢查。

3 分鐘學會圖片修復

  1. 加入圖片：點選左側「選擇圖片」或把多張圖片拖進來。
  2. 選取浮水印：右下角 KlingAI 3.0 和 DreaminaAI 可直接修復，也可先按「右下角浮水印遮罩」確認遮罩。其他版型請框選或使用筆刷。可按「亮色精選」將矩形變成白色文字的近似遮罩。
  3. 修補與檢查：按「修復目前圖片」，使用「前後對比」與縮放查看效果；必要時使用仿製圖章手動細修。
  4. 整批處理：勾選其他圖片後按「批次修復」，完成後下載 ZIP。

仿製圖章：選擇「仿製」，按住 Alt（Mac 為 Option）點一下乾淨的參考位置，再在浮水印處畫筆。也可選擇工具後按「選擇來源點」提示操作。所有處理均在本機完成。
